How to join

  1. Install CoHiro. It is on the App Store, and coming soon to Google Play.
  2. Create an account, or sign in if you already have one.
  3. Go to the Household tab, choose Join a household, and enter the code above.

What is CoHiro?

One shopping list the whole household can add to, and a picture of what is actually in the cupboard. Anything that runs low puts itself on the list, so remembering is not one person's job. More about CoHiro.

An invite code lets you join one household. It expires, and whoever sent it can revoke it at any time. It contains nothing about you, and nothing about them: see the privacy policy.
